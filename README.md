## 🚀 My Projects

Here are some of the projects I'm working on or have contributed to:

- [pushpasta/wp-plugin-readme2md](https://github.com/pushpasta/wp-plugin-readme2md) – A GitHub Action that converts WordPress plugin readme.txt files into GitHub Markdown. Generate clean README.md files automatically as part of your workflow.
- [pushpasta/simple-honeypot-cf7](https://github.com/pushpasta/simple-honeypot-cf7) – Hidden honeypot fields, timing checks, proof-of-work, custom rules, and spam reporting for Contact Form 7. Everything runs on your server — no external services, no visitor tracking.
- [pushpasta/email_domains_mapper](https://github.com/pushpasta/email_domains_mapper) – A Roundcube (RC) plugin for multi domain email setups. It connects users to the right mail servers based on their email domain.
